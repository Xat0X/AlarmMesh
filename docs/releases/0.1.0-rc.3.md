# AlarmMesh 0.1.0-rc.3

Open bij een actieve rookmelding **Groepen → je groep → Stop meeklinken in deze groep**. De knop staat ook bij de groep in het actuele incident. Boven de knop staan de melders die AlarmMesh kan stoppen.

Als de melder op de overloop rook meldt, kun je met één druk het meeklinken van de melders in de hal en de berging stoppen. Dat kan zodra AlarmMesh de start van hun Heiman-sirene heeft bevestigd. Meldt de melder in de hal intussen zelf rook, dan slaat AlarmMesh die melder over. Een onzekere rookstatus of een sirene die tegelijk voor een andere actieve groep klinkt, sluit die melder eveneens uit. Voor de Aqara JY-GZ-01AQ blijft alleen starten beschikbaar.

Open na je test **Activiteit → Rook en startopdrachten**. Per melder zie je welke stop de groepsknop heeft aangevraagd. Vergelijk die tijden met wat je thuis hoorde.

## Installeren via HACS

Maak vóór de update een back-up van Home Assistant. Kies in HACS bij AlarmMesh de prerelease **0.1.0-rc.3**, herstart Home Assistant en herlaad het paneel. Samen afgaan staat standaard uit voor nieuwe groepen. Een update bewaart eerder ingestelde koppelingen.

Wil je terug naar RC2, herstel dan de back-up van vóór de update zodat de versie en de bijbehorende tijdlijngegevens bij elkaar passen.
