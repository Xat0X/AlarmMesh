# AlarmMesh 0.1.0-beta.9

Open a detector and choose View alarm route to preview its groups, shared sounder targets, phone recipients and ordered scripts. Opening the preview sends no commands.

Source recovery transfers selected group memberships to a replacement detector. Home Assistant source selection is a separate step. Previous control permissions and incident history stay with their original identities. If the connection drops during a save, the panel reads back current memberships on reconnect. It never retries the save automatically. Refreshing a self-test dialog requires fresh confirmation.

Linked sounding defaults off. Updates preserve existing explicit settings. Testing used simulated sources. Physical detectors were not operated.

Back up Home Assistant, enable pre-releases for AlarmMesh in the installer, select 0.1.0-beta.9 and restart when prompted. For manual installation, extract alarmmesh.zip inside custom_components/alarmmesh and restart. Restore the pre-update backup for rollback.
