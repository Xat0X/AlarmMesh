# AlarmMesh 0.1.0

AlarmMesh's first stable release brings your existing Home Assistant smoke detectors into a single panel. A smoke alert identifies the reporting detector on your phone. Tap it to see which detectors are reporting smoke, which others are sounding along, and which linked sounders you can stop.

## Explore the integration

- Use **Overview → Silent practice** to walk through a detector's alarm route on screen with your family.
- Choose phones, optional group sounders and Home Assistant scripts separately. New groups start with linking off. A detector reporting its own smoke is excluded from a group stop, and AlarmMesh never requests Aqara mute.
- Open **Maintenance** for device-reported battery readings, checks and a maintenance journal. Open **Activity** to review smoke reports, commands and siren feedback after an incident.

## Install or upgrade from RC5

Back up Home Assistant, install **0.1.0** using Marketplace or HACS as appropriate for your version, and restart Home Assistant after updating. Existing selections and group settings carry forward. New users can start with monitoring and explore the silent exercise before enabling automatic actions. [Illustrated guide](https://github.com/Xat0X/AlarmMesh/blob/0.1.0/README.md) · [Installation instructions](https://github.com/Xat0X/AlarmMesh/blob/0.1.0/docs/installation.md)

**Safety notice.** AlarmMesh is a supplementary tool provided as is, without warranty. It cannot replace certified smoke alarms or a certified fire alarm system. During a fire, detection, linked sound and phone notifications can fail. Never rely on AlarmMesh alone for your safety.
