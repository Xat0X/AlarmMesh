# AlarmMesh 0.1.0-beta.8

This opt-in beta adds smoke sources from the Home Assistant Matter and Z-Wave JS integrations. Select the smoke entity in AlarmMesh options to include it in rooms, groups and incident reporting. Optional battery and problem details depend on the entities exposed by Home Assistant.

Matter self-test requests require a compatible button on the same endpoint. Z-Wave JS support reads smoke and health information. Neither provider adds remote sounder targets. Linked sounding defaults off. An update preserves previously confirmed settings. Selected unsent forms can now survive a page reload and still require fresh confirmation.

Back up Home Assistant before updating. Enable pre-releases for AlarmMesh in the installer, select 0.1.0-beta.8 and restart when prompted. For a manual install, extract alarmmesh.zip into custom_components/alarmmesh and restart. To roll back, restore the pre-update backup. Validation uses simulated devices. Physical detection, sound and radio operation remain unverified.
