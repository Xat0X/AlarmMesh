# AlarmMesh 0.1.3-beta.2

This beta adds two Zigbee2MQTT detectors that you can select as smoke sources without a template helper. It also includes the Alecto SMART-SMOKE10 support introduced in beta 1.

| Detector | Source to select in AlarmMesh | Expected reading |
| --- | --- | --- |
| AVATTO ZSD20 | **Smoke sensor state** | `alarm` reports smoke and `normal` clears it. An unknown or unavailable reading leaves the smoke status indeterminate. |
| Sunricher SR-ZG9070A-SS | **Smoke alarm 1** and **Smoke alarm 2** | Add both inputs to the same group. A smoke report on either input keeps the group in alarm, even if the other input goes offline. If one input is offline and the other is clear, the group shows an indeterminate smoke status. |

## Try the beta

1. Open **AlarmMesh** in HACS. Choose **Download** (or **Redownload** for an existing installation), open **Need a different version?**, and select **0.1.3-beta.2**. Restart Home Assistant after installation.
2. In **AlarmMesh → Detectors → Choose detectors**, select the inputs listed above and save. For the Sunricher, include both inputs when setting up your group.
3. Compare the readings in AlarmMesh with the same entities in Home Assistant. If you share feedback, include the model, Home Assistant and Zigbee2MQTT versions, the inputs that appeared, and the reading shown by each application.

Both new models support monitoring. Linked sounding is off by default. The compatibility checks use simulated devices on Home Assistant 2026.10.4 and 2026.11.1.
