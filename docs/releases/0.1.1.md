# AlarmMesh 0.1.1

Use the installation button in the README to open AlarmMesh directly in your own Home Assistant. It takes you to the Marketplace on Home Assistant 2026.11 or later, or to HACS on 2026.10.4. If prompted, confirm adding the repository and choose **Install**. [Open AlarmMesh in Home Assistant](https://my.home-assistant.io/redirect/hacs_repository/?owner=Xat0X&repository=AlarmMesh&category=integration)

The examples in the documentation, release notes and automated tests use neutral detector names. Review guides now refer to their evidence folders by relative name.

If you already run 0.1.0, install the update from your usual Home Assistant update screen and follow the restart prompt. Your existing detector and group selections carry forward. New groups start with linked sound off.
