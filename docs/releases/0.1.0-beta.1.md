# AlarmMesh 0.1.0-beta.1 — Interface preview

This is an opt-in test release for trying AlarmMesh on an existing Home Assistant
installation. It is a pre-release, not a stable or certified alarm product.

## Before updating

1. Create a Home Assistant backup and retain its recovery information privately.
2. Record the currently installed AlarmMesh revision. This beta adds group storage
   and a frontend panel; restoring a known-good backup is the recovery route.
3. In Marketplace, open AlarmMesh, enable **Pre-release**, then select
   **0.1.0-beta.1** in the install/reinstall/version dialog. Older HACS installations
   can enable beta versions and select this release through their version dialog.
4. Update through the installer and restart Home Assistant as prompted. Refresh
   the browser after restart if it still shows the previous interface.
5. Sign in as a Home Assistant administrator and open **AlarmMesh** in the sidebar.
   Existing source selections and overview identities are retained. Groups start
   empty if this is the first panel version installed.

The repository remains on its normal source-folder installation route; no manual
ZIP extraction or frontend-resource configuration is needed.

## Included

- Overview of current smoke reports and completeness of source information.
- Selected detector details and rooms from Home Assistant's own assignments.
- Persistent organizational groups with admin-only editing and conflict checks.
- Dutch/English text, light/dark themes and phone/tablet layouts.
- Full-height backgrounds, aligned icons and simplified group-page copy.

## Test scope and limits

Technical checks target exactly HA **2026.10.4** and **2026.11.1**. The validation
workflow runs 277 backend tests, 11 frontend tests, hassfest and 14 technical
scenarios per target. Check the linked GitHub Actions run for the tagged commit.
Earlier visual acceptance used a separate HA 2026.11.1 simulation environment.

The panel is administrator-only. Two existing overview entities remain available
under normal HA permissions. Groups organize sources; they do not link alarms.
Battery values, radio-contact freshness and device capabilities are not guessed.

There is **no siren control, notification sending, alarm propagation, mute/reset
or device-test action**. No smoke reported is not a guarantee of safety;
incomplete smoke information is never silently converted to no smoke reported.
This beta must not replace certified standalone smoke detectors.

Marketplace/backup acceptance of the earlier 0.0.1 payload is separate from this
new panel release. Upgrade acceptance for this beta on an existing installation,
physical-device transitions and production recovery remain pilot activities.
The Marketplace README's wide logo may have low contrast on a dark background;
the integration/panel icon is separate and was visually checked.
