# AlarmMesh 0.1.2

AlarmMesh now uses the time zone already loaded by Home Assistant when you save, snooze or mark a maintenance reminder as handled. This avoids reading time zone files on Home Assistant’s event loop.

Existing reminders follow the configured local calendar. A reminder falls due at 09:00 local time, including after a daylight-saving change. You can install the update and restart Home Assistant without recreating your reminders.
