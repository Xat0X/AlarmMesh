# AlarmMesh 0.1.3-beta.1

This beta adds the Alecto SMART-SMOKE10 as a smoke source through Zigbee2MQTT. You can select its **Smoke state** sensor directly in AlarmMesh. No template helper is needed.

## Try the beta

1. Enable pre-releases for AlarmMesh in HACS or the Home Assistant Marketplace, install **0.1.3-beta.1**, then restart Home Assistant.
2. Open **AlarmMesh → Detectors → Choose detectors**. Choose **Smoke state** on the Alecto MQTT device. If you previously selected a retired Tuya entity for the same detector, deselect it and save.
3. Compare Home Assistant's **Smoke state** with the detector in AlarmMesh. A value of `normal` should show **No smoke reported**. You can check discovery and this reading without triggering an alarm.

The simulator covered `alarm`, `normal`, loss of availability and recovery on Home Assistant 2026.10.4 and 2026.11.1. An unavailable detector appears as unreachable and its smoke status is indeterminate. Alecto support is read-only. Linked sounding is off by default.

Feedback from physical installations is welcome. Please include your Home Assistant and Zigbee2MQTT versions, whether **Smoke state** appeared in the picker, and the observed status in each app.
