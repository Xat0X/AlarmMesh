# AlarmMesh 0.1.0-beta.10

A calmer mobile overview puts current status and affected detectors first. Detector alarm routes and phone settings are easier to reach, group forms start with name and members, and optional actions remain available in expandable sections. Dutch and English layouts retain visible smoke information while forms are open.

Source recovery is directly available beside a missing, unavailable or identity-changed source. Temporary outages are explained separately. Only explicitly selected group memberships transfer. If the connection drops before a request is sent, memberships remain unchanged. If the save response is lost, reconnect shows the actual saved memberships without automatically retrying. Existing identities, confirmations and control permissions remain enforced.

Linked sounding defaults off. Updating preserves existing explicit settings; it does not enable linking or new automatic actions. No physical detector, phone or production installation was operated during validation. Real-device acceptance remains separate from simulated tests.

Back up Home Assistant before updating. Enable pre-releases for AlarmMesh in your installer and select 0.1.0-beta.10, then restart when prompted. For manual installation, extract alarmmesh.zip into custom_components/alarmmesh and restart. Restore the pre-update backup to roll back.

Validation: 548 backend tests and 92 frontend tests passed. Ruff, formatting, hassfest, PowerShell and Compose checks passed. Isolated compatibility checks passed on Home Assistant 2026.10.4 and 2026.11.1. Two identical builds contain 41 integration files. Browser recovery checks covered normal save, disconnect before sending, and lost acknowledgement after saving.
